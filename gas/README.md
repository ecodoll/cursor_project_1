# 구글 시트로 가계부 데이터 저장하기

화면은 Vercel에 두고, 거래·분류·자산은 비공개 구글 시트에 저장합니다. 둘이 정한 비밀번호가 맞을 때만 시트를 읽고 씁니다. 비밀번호는 각 휴대폰·브라우저에 한 번 저장됩니다.

## 1. 시트 만들기

1. [구글 시트](https://sheets.google.com)에서 빈 스프레드시트를 만듭니다. 이름은 `가계부`처럼 알아보기 쉬운 것으로 두면 됩니다.
2. 시트는 **링크 공개를 하지 않습니다.** 기본값(나만 보기) 그대로 둡니다.
3. 탭 이름(`transactions`, `categories` 등)은 비워 두어도 됩니다. 스크립트가 처음 연결될 때 만들고, 분류·자산 기본값도 넣습니다.

이미 쓰던 내역이 있으면 헤더를 맞춘 뒤 그 아래에 붙여 넣습니다.

`transactions` 헤더:

`id`, `date`, `type`, `amount`, `asset_type`, `memo`, `category_id`, `l1`, `l2`, `l3`, `created_at`, `updated_at`

- `type`은 `income` 또는 `expense`
- `date`는 `2026-10-22` 형식
- `id`가 비어 있는 예전 행은 시트에서 직접 고유 값을 채워 주세요.

`categories` 헤더: `id`, `l1`, `l2`, `l3`

`asset_types` 헤더: `name`

`memo_learn` 헤더: `keyword`, `l1`, `l2`, `l3`, `category_id`, `updated_at`

## 2. 스크립트 넣기

1. 시트 메뉴 **확장 프로그램 → Apps Script**.
2. 기본 `Code.gs` 내용을 지우고, 이 폴더의 `Code.gs` 전체를 붙여 넣습니다.
3. 왼쪽 톱니바퀴 **프로젝트 설정**.
   - 시간대: `Asia/Seoul`
   - **스크립트 속성** → 속성 추가
     - 속성: `APP_PASSWORD`
     - 값: 둘이 쓸 비밀번호
4. 저장합니다. 비밀번호는 코드나 시트 칸에 넣지 않습니다.

## 3. 웹 앱으로 배포

1. 오른쪽 위 **배포 → 새 배포**.
2. 유형: **웹 앱**.
3. 실행 계정: **나**.
4. 액세스 권한: **모든 사용자**. (구글 로그인 없이 두 휴대폰에서 열기 위한 설정입니다. 시트 파일 자체는 공개되지 않고, 비밀번호가 맞는 요청만 처리합니다.)
5. 배포 후 나오는 `/exec` 로 끝나는 웹 앱 URL을 복사합니다.

코드를 수정한 뒤에는 **배포 관리 → 연필 아이콘 → 버전: 새 버전**으로 다시 배포해야 반영됩니다.

## 4. Vercel에 주소 넣기

Vercel 프로젝트 → **Settings → Environment Variables**

| 이름 | 값 |
|---|---|
| `APPS_SCRIPT_URL` | 3번에서 복사한 `/exec` 주소 |

Production에 넣은 뒤 한 번 다시 배포합니다. 이 주소는 저장소에 올리지 않습니다.

## 5. 사용

사이트에 접속해 비밀번호를 입력합니다. 맞는 비밀번호는 그 브라우저에 남아서, 다음부터는 바로 가계부가 열립니다. 다른 휴대폰에서는 그 기기에서 한 번 입력합니다.

설정 → **잠금**의 **이 기기에서 잠그기**는 그 브라우저에 기억된 비밀번호만 지웁니다. 시트의 데이터는 그대로입니다.

아내가 넣은 내역은 앱을 다시 열거나, 화면으로 돌아왔거나, **지금 다시 불러오기**를 눌렀을 때 보입니다. 저장 직후 상대 화면이 저절로 바뀌지는 않습니다.
